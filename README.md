# QA_Game - 슬라임 사냥 (원본 / 수정본 비교)

QA 테스트케이스·버그리포트 작성 연습을 위해 만든 턴제 전투 웹게임입니다.
**원본 버전**과 결함을 수정한 **수정 버전(v2)**을 한 페이지에서 전환하며 직접 테스트할 수 있습니다.

▶ **플레이 / 테스트하기: [https://pigpenguinman.github.io/QA_Slimehunt/]**

## 사용 방법

1. 페이지 상단의 **원본 버전 / 수정 버전 (v2)** 탭으로 버전을 전환합니다.
2. 각 버전은 진행 상태를 따로 유지합니다. 같은 상황을 두 버전에서 번갈아 실행해 결과를 비교할 수 있습니다.
3. **초기화** 버튼은 현재 보고 있는 버전만 처음 상태로 되돌립니다. (새로고침 불필요)

## 게임 규칙

- 시작 상태: HP 100, MP 30, 골드 10, 포션 3개
- 공격(10~15 피해), 스킬(MP 10 소모, 25 피해), 방어(피해 감소), 포션(HP +30)
- 승리 시 골드 +20, EXP +30, EXP 100 도달 시 레벨업
- 상점에서 15골드로 포션 구매

## 두 버전 비교

| 구분 | 원본 버전 | 수정 버전 (v2) |
|---|---|---|
| 상태 | 결함이 포함된 상태 | 원본에서 발견한 결함을 수정한 상태 |
| 테스트 목적 | 결함 탐지, 테스트케이스·버그리포트 작성 | 수정 확인, 주변 기능 회귀 테스트 |
